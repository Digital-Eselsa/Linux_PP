# Task Overview

## Objective

Demonstrate understanding of basic Linux commands by completing the activity as a newly created user in Kali Linux.

## Activity Steps

1. Create and switch to `student01`.
2. Build the required project directory structure.
3. Create, edit, copy, move, and rename files.
4. Configure permissions with `chmod`.
5. Delete `admin_notes.txt`, create `backup`, and copy the contents of `docs` and `scripts`.
6. Run final checks with `tree project` and `ls -la`.
7. Optionally record command history in `commands_used.txt`.

The terminology and requirements in this document are taken directly from the supplied task.
