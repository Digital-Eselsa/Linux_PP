# Submission

Complete the practical task first, then prepare the required evidence.

## Submission Preparation

Review:

- Final `tree project` output.
- `ls -la` output for the relevant directories/files.
- Required screenshots.
- Optional command history, if you completed the bonus task.

If the instructor requires command history, place the actual content in `command-history.txt`.

If a final terminal output transcript is required, place your real output in `final-output.txt`.
